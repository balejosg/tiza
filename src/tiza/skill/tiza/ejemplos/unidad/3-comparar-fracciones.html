Cómo se comparan dos fracciones con el mismo denominador o con denominadores distintos.

Qué vas a aprender

  • Comparar dos fracciones con el mismo denominador.
  • Comparar dos fracciones con distinto denominador.

Mismo denominador

Para comparar dos fracciones con el mismo denominador basta mirar el numerador.

Denominadores distintos

Si el denominador es distinto, buscamos fracciones equivalentes con un denominador común. La tabla muestra 2/3 y 3/5 escritas con denominador 15:

FracciónCon denominador 15
2/310/15
3/59/15

Ejemplo

¿Qué fracción es mayor, 2/3 o 3/5?

Ver la solución

Con denominador 15: 10/15 y 9/15. Es mayor 2/3.

Recuerda

Si los denominadores son distintos, busca primero fracciones equivalentes con un denominador común.

Palabras de esta página

Fracciones equivalentes
Se escriben distinto y valen lo mismo, como 1/2 y 2/4.
Denominador común
Un mismo denominador para las dos fracciones que comparas.

Resumen

  • Con el mismo denominador, es mayor la que tiene el numerador mayor.
  • Con denominadores distintos, compara fracciones equivalentes con un denominador común.
